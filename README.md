# Mahalle Dostları

Sokak hayvanlarını besleme oyunu. Mini İstanbul: Sultanahmet, Gülhane, Eminönü, Galata Köprüsü ve Galata.

- **Tarayıcıda oyna:** https://icanyesilyurt.github.io/mahalle-dostlari/
- **Android APK:** https://icanyesilyurt.github.io/mahalle-dostlari/MahalleDostlari.apk

Godot 4.4 ile yapıldı. Harita `tools/build_map.gd` ile kurulup `map/istanbul.scn` olarak kaydedilir.
Kenney Starter Kit karakteri (MIT), Baloo 2 yazı tipi (OFL).
